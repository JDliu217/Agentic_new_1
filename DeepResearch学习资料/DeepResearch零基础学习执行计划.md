# DeepResearch 零基础学习执行计划

## 目标

最终目标不是背文件名，而是能独立回答：

1. 用户在页面做一个动作后，代码从哪里开始执行？
2. 请求经过哪些 Router、Service、Agent 和数据存储？
3. 每一层传入和传出的数据是什么？
4. 如何用日志、请求、数据库和前端状态定位故障？
5. 当前实现、设计目标和未验证部分分别是什么？

## 学习规则

每一课都按以下顺序进行：

```text
概念解释
  → 源码入口
  → 一条真实数据流
  → 最小练习
  → 你的回答
  → 源码证据验收
  → 补课或进入下一课
```

你不需要一次读完所有文件。每次只追踪一条页面动作到后端结果，逐步建立工程直觉。

## 阶段安排

### 阶段 0：理论地基

材料：第 9 课、第 1 课。

掌握 HTTP、JSON、异步函数、SSE、数据库、缓存、向量检索、LLM、Agent 和状态机的基本含义。

通过标准：能用自己的话解释“浏览器为什么能收到一段一段的研究结果”。

### 阶段 1：项目全景

材料：第 1、14、15、24、45、46 课。

掌握 React → FastAPI → DeepResearch V2 → ResearchState → SSE → React 的主链路，以及六个 Agent 的职责。

通过标准：能画出一次研究请求，并指出当前默认走 `_run_simplified()`。

### 阶段 2：认证、会话和普通聊天

材料：第 17、28、41 课。

掌握注册、登录、JWT、会话、消息持久化、旧 Redis Session 和 PostgreSQL 新会话的边界。

通过标准：能解释一个 Token 从登录响应到后端权限依赖的全过程。

### 阶段 3：DeepResearch 六个 Agent

材料：第 2 至 6、15、25 课。

掌握规划、搜索、分析、代码执行、写作、审核的输入输出和失败路径。

通过标准：给定一个 Agent 文件，能指出它读哪些状态字段、写哪些字段、调用哪些外部能力。

### 阶段 4：RAG、知识库和长期记忆

材料：第 13、20、21、26、43 课。

掌握文档上传、解析、切片、Embedding、Milvus、召回、引用、长期记忆以及旧文档兼容链。

通过标准：能解释 PostgreSQL 的文档元数据为什么不能替代 Milvus 向量。

### 阶段 5：数据分析、Text2SQL 和 CodeWizard

材料：第 10、12、29、30、47、48 课。

掌握自然语言到 SQL、数据洞察、代码生成、图表配置和前端渲染的区别。

通过标准：能解释 `compile()` 为什么不是安全沙箱，并能追踪一张图表从数据到 ECharts 的路径。

### 阶段 6：检查点、取消、恢复和外围业务

材料：第 18、22、33、34、35 课。

掌握行业资讯、招投标、股票、检查点、取消和恢复。

通过标准：能区分 `ResearchState`、`state_json`、`ui_state_json` 和会话消息。

### 阶段 7：工程启动、配置和排错

材料：第 16、27、32、36、37、40、42、44 课。

掌握 Docker、两套 Compose、依赖、环境变量、Mock、测试资产、Vite、TypeScript、ESLint 和分层排错。

通过标准：能判断一个失败属于容器、后端、前端、数据存储还是外部 API，并给出下一条证据。

## 第一轮作业：第 1 课

请不看源码，先回答下面 7 题。回答不要求术语完美，但要写出“谁调用谁、数据去了哪里”。

1. 为什么 `/research/stream` 使用 SSE，而不是等所有 Agent 完成后返回一个 JSON？
2. `ResearchState` 在六个 Agent 之间起什么作用？
3. 当前默认真正执行的是 LangGraph 图还是 `_run_simplified()`？你准备在哪里找证据？
4. DataAnalyst 和 CodeWizard 都可能产生图表，它们的职责有什么不同？
5. 为什么进程内 `exec()` 加正则拦截不能算生产级安全隔离？
6. 上传知识库文档后，PostgreSQL 和 Milvus 各保存什么？
7. V1 ReActController 和 V2 六个 Agent 的核心架构差异是什么？

## 回答格式

建议每题使用这个格式：

```text
我的理解：

源码证据（如果记得文件名就写）：

我不确定的地方：
```

我会逐题指出正确部分、缺失部分和混淆点，并要求你补上能在源码中定位的证据。全部通过后再进入第 2 课。

答题时可以参考但不要先阅读答案的证据定位文件：`DeepResearch第1课答题证据索引.md`。

## 运行验证边界

目前已确认：Python 编译通过，Vite build 通过；TypeScript 严格检查和 ESLint 仍有项目既有错误。Docker、PostgreSQL、Redis、Milvus、外部搜索、DocMind 和真实 LLM 尚未完成本机端到端验证。学习过程中会明确区分“源码确认”和“真实运行确认”。

## 面试阶段

只有在学习验收清单的主干项目、数据流、工程排错和面试表达项目通过后，才进入模拟大厂面试。小红书面经分析暂缓，等你提供后续 Prompt 后再处理。
