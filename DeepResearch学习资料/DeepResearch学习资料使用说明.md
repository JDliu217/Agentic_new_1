# DeepResearch 学习资料使用说明

## 1. 学习目标

这套资料的目标不是只记住某个接口，而是建立一条完整的工程理解链：

```text
用户问题 -> API 路由 -> 服务层 -> Agent 编排 -> 外部工具/模型 -> 状态持久化 -> SSE -> 前端展示
```

学习时应能回答三个问题：

1. 一个请求从哪里进入系统，经过哪些模块，最后如何返回用户界面？
2. 每个模块保存了什么数据，依赖了哪些外部服务？
3. 某个环节失败时，如何定位、降级和恢复？

## 2. 推荐顺序

### 第一遍：建立地图

先阅读《项目一页总图与背诵版》《项目总学习路线与文件索引》《文件级阅读清单》。这一遍只确认目录、角色和主数据流，不要求记住所有细节。

### 第二遍：沿着一条请求阅读

重点跟读普通聊天和 DeepResearch V2：从前端请求开始，进入路由，经过服务层和 Agent，最后回到 SSE 和 React 渲染。每读完一个模块，在纸上写出输入、输出和失败处理。

### 第三遍：补基础设施

再学习认证、会话、RAG、Milvus、长期记忆、Text2SQL、检查点、取消恢复和 Docker。此时要把“业务流程”和“基础设施依赖”联系起来。

### 第四遍：做验证

使用《接口地图与数据契约》《工程排错》《阶段验收答题表》逐项检查。遇到无法真实启动的依赖，要明确区分“代码路径已读懂”和“运行环境已验证”。

## 4. 学习完成标准

完成学习后，应能不看资料画出 V2 主链路，解释 `ResearchState`、SSE、Milvus 和检查点的关系，并能说明当前实现与生产级实现之间的差距。

不要把“接口返回 200”当作系统完全正确。还要检查权限、状态一致性、外部依赖、超时、取消、恢复和可观测性。
